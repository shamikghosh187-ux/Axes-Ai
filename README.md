# KEPLER MIND

**Explore the unknown. Understand the universe.**

KEPLER MIND is a scientific exploration project. Its research workspace, **ORIGIN**, is designed to help researchers organise investigations and move from questions toward traceable evidence and understanding.

## ORIGIN workspace

The current interface foundation includes:

- A research overview and workspace navigation.
- Project creation with a research domain and research question.
- Dedicated interface areas for literature, evidence, hypotheses, and reports.
- A responsive dark interface with warm amber accents.

> **Current status:** this repository currently contains the ORIGIN UI foundation. Project data is held in client-side state and is not persistent. Literature discovery, document processing, evidence mapping, hypothesis analysis, report generation, authentication, and connected AI research are not currently implemented as working features.

## Technology

- Next.js App Router
- React
- TypeScript
- Lucide icons

## Run locally

You need Node.js and npm installed.

\`\`\`bash
git clone https://github.com/shamikghosh187-ux/Axes-Ai.git
cd Axes-Ai
npm install
npm run dev
\`\`\`

Open [http://localhost:3000](http://localhost:3000).

Create a production build with:

\`\`\`bash
npm run build
\`\`\`
